## Eight ways in, one engine

  
Whatever you install talks to the same checking core. Each channel page carries an install
command, a quick start that was actually executed, and the capability notes — what is native,
what goes over the wire. Start from the
[channel catalog](/install) if you
are not sure which is yours.

caches. These pages document each piece as it exists today — where something
